# 硬件接线指南 —— 红色座机 ↔ CM108 USB 声卡

> 本文目标：把淘宝买的**复古红色固定座机**（¥150-300）改造成**USB 输入输出音频设备**，插到 Windows 电脑上即可被 `sounddevice` 当成普通 mic/speaker。

## 🔌 红色座机内部结构

拆开后盖（一般就 4 颗十字螺丝），你能看到：

```
                ┌──────────────────┐
                │  主体 PCB + 喇叭  │
                │                  │
                │  ┌─────────────┐ │
   手柄线(4芯)──┼──┤ 手柄  插座  ├─┼── 桌机线(2-4芯)
                │  └─────────────┘ │
                │                  │
                └──────────────────┘
```

**手柄** = 话筒（MIC）+ 听筒（EAR）合在一起的二合一。
手柄线下到主机一般是 **4 芯屏蔽线**：

| 颜色（常见） | 含义 |
|---|---|
| 红色 | MIC + (话筒供电) |
| 白色 / 蓝色 | MIC - (话筒地) |
| 绿色 / 黄色 | EAR + (听筒信号) |
| 黑色 / 棕色 | EAR - / 公共地 |

> ⚠️ 不同厂家颜色不一样！**先量通断再焊** —— 万用表打到通断档，量每根线和手柄端 MIC+ / MIC- / EAR+ / EAR- 的对应关系。

---

## 🎤 手柄话筒（MIC）→ CM108 MIC 输入

CM108 的麦克风接口一般是 **3.5mm 母座**，信号定义：

| 针脚 | 信号 |
|---|---|
| Tip | MIC 信号 |
| Ring | MIC 偏置 / 接地 |
| Sleeve | 地 |

**接线**：

```
手柄 MIC+ (红色)    ──→  3.5mm Tip
手柄 MIC- (白/蓝)  ──→  3.5mm Sleeve (地)
```

CM108 自带 mic bias（+2.5V 上拉），所以**不需要**再额外供电，电容/动圈话筒都能直接用。

---

## 🔊 主机喇叭（EAR）→ CM108 EAR 输出

CM108 的耳机输出口是 **3.5mm 立体声母座**：

| 针脚 | 信号 |
|---|---|
| Tip | L |
| Ring | R |
| Sleeve | 地 |

红色座机的听筒喇叭通常是 **单声道 8Ω 0.5W**。直接接 L 声道即可：

```
CM108 EAR L (Tip)  ──→  主机 EAR+ (绿/黄)
CM78 地 (Sleeve)   ──→  主机 EAR- (黑/棕)
```

> ⚠️ CM108 输出功率较小（~30mW），但驱动一个 0.5W 的听筒喇叭绰绰有余。音量通过 Windows 音量调节。

## 🧷 物理装配建议

1. CM108 模块**塞进座机内部**，用热熔胶固定在底板上
2. USB 线**从座机后部**（原本电话线出口）穿出来 → 插电脑
3. 保留原有电话线入口（**不用接真的电话线**），仅作为 USB 出口
4. 在座机外壳上**钻一个 3.5mm 母座孔**（可选，方便插拔），或者直接把线焊死

## ✅ 接线后验证

把 USB 插到电脑，Windows 应自动识别为 "USB Audio Device"。在 `sounddevice` 里能看到：

```python
import sounddevice as sd
print(sd.query_devices())
# 找到 "USB Audio Device" 设备，记录 index
```

测试代码：

```python
import sounddevice as sd
import numpy as np

# 录音 3 秒
sr = 16000
rec = sd.rec(int(3 * sr), samplerate=sr, channels=1, dtype='int16')
sd.wait()
print("录音能量:", np.sqrt(np.mean(rec.astype(np.float32) ** 2)))

# 播放
sd.play(rec, samplerate=sr)
sd.wait()
```

对着话筒说话，应该能在 `play()` 时听到自己的声音。如果听不到，检查 EAR+ / EAR- 是否反接。

## 🆘 常见坑

1. **话筒声音小 / 失真**：CM108 mic bias 默认 2.5V，有的座机话筒需要 1.5V，可以在 mic 线和地之间串一个 1kΩ 电阻衰减。
2. **听筒有底噪**：EAR 信号线和电源线太近 → 用屏蔽线 + 飞线远离 USB 电源。
3. **系统识别不到 CM108**：换 USB 口（前置口供电不足），或换根数据线（有的充电线只有电源）。
4. **话筒和喇叭互相串扰（听到自己说话）**：座机手柄电路没分开 mic / ear 通道，正常 —— 这是真实电话的特性。如果太严重，物理上把话筒和喇叭拉远一些。
